## BinaryBaconLabs

Small team building internal tools. Most of what we do lives in private repos (`todo-app-infra`, `platform-ops`);
the frontend is public and we are happy to take contributions.

- [todo-app](https://github.com/BinaryBaconLabs/todo-app): React frontend. CI runs on our self-hosted runner and
  deploys to AWS from `main`. Issues tagged `good first issue` / `hacktoberfest` are ready to pick up.

Contribution notes are in each repo's `AGENTS.md` and `docs/`. Questions: open an issue, jarman reads them daily.

_Weekly release notes are posted on Fridays._
